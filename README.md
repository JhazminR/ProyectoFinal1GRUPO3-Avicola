# ProyectoFinal1_GRUPO3-Avicola
Proponer el diseño sistema web que permita analizar el rendimiento laboral en los procesos productivos de una empresa avícola en la ciudad de Trujillo, mediante el registro, procesamiento y visualización de datos de los trabajadores en sus distintas áreas, con el fin de apoyar la toma de decisiones basada en información objetiva.
El presente proyecto contempla el diseño de una aplicación web orientada al registro y análisis del rendimiento laboral de los trabajadores de una empresa avícola. El sistema permitirá almacenar información relevante de los empleados, así como registrar las actividades que realizan dentro de sus respectivas áreas de trabajo. Asimismo, se incluirán funcionalidades que faciliten el control de asistencia, el seguimiento de tareas y la evaluación del desempeño laboral a través de métricas básicas. A partir de esta información, el sistema generará reportes que permitirán visualizar el nivel de productividad tanto de manera individual como por área. De igual manera, se incorporarán herramientas de visualización, como gráficos y paneles de control (dashboards), con el propósito de facilitar la interpretación de los datos y apoyar la toma de decisiones.
